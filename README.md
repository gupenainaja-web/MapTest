# MAP Math & Science ป.1–ม.3

ระบบจำลองการสอบ MAP แบบปรับระดับ (Adaptive) วิชา Mathematics และ Science (ภาษาอังกฤษ) สำหรับ ป.1–ม.3

- สอบปรับระดับ 20/30/40 ข้อ · รายงานผลรายสาระ · ชุดฝึกเฉพาะคน
- คลังข้อสอบ 215 ทักษะ พิมพ์ใบงานพร้อมเฉลยได้
- ข้อมูลนักเรียนและผลสอบเก็บใน **เบราว์เซอร์ของเครื่องที่ใช้งาน** (localStorage)
  - กด **สำรองข้อมูล (.json)** ที่หน้าแรกเป็นประจำ
  - ใช้ **นำเข้าข้อมูล** เพื่อย้ายข้อมูลไปเครื่องอื่นหรือกู้คืน

## เผยแพร่ด้วย GitHub Pages
1. อัปโหลด `index.html` ไว้ที่ root ของ repository (branch `main`)
2. Settings → Pages → Build and deployment → Source: **Deploy from a branch** → Branch: `main` / `(root)` → Save
3. รอ 1–2 นาที เว็บจะอยู่ที่ `https://<ชื่อบัญชี>.github.io/<ชื่อ repository>/`

> คะแนนสเกลในระบบนี้เป็นสเกลของสถาบัน ออกแบบให้คล้าย RIT แต่ไม่ใช่คะแนนทางการของ NWEA
